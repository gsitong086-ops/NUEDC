一、淘晶驰上位机新建工程
================================================================

1. 打开「淘晶驰上位机」软件
2. 菜单栏 → 文件 → 新建工程
3. 弹出窗口中：
   - 设备型号：下拉选择「TJC8048X270_011C」
   - 分辨率：  自动填充 800×480
   - 屏幕方向：横屏（Landscape）
   - 工程名：   waveform_display
   - 保存路径：选择一个目录
4. 点击「确定」，进入编辑界面

【控件6】波形显示控件 (wave0)
  类型：Waveform（波形控件）
  属性：
    objname = "wave0"      ← ★ 必须命名！
    x       = 10
    y       = 60
    w       = 780          ← 占满可用宽度
    h       = 290          ← 波形区域高度
    ch      = 1            ← 通道数量（单通道）
    dir     = 3            ← 滚动方向：3=从左到右
    dis     = 1            ← 显示模式：1=连续滚动
    gd      = 80           ← 网格水平间距（像素）
    gdh     = 80           ← 网格垂直间距（像素）
    gdc     = 0x333333     ← 网格线颜色（深灰）
    bgc     = 0x000000     ← 背景色（黑色）
    pco0    = 0x00FF00     ← 通道0波形颜色（绿色）
    pco1    = 0xFF0000     ← 通道1波形颜色（红色，备用）

  对应代码（main.c 中）：
    // 每次往波形追加一个数据点
    uint16_t adc_val = adc_buf[0];
    uint8_t  v       = (uint8_t)(adc_val >> 4);  // 12bit→8bit
    HMI_AddWave("wave0", 0, v);
    // 等价于发送：add wave0,0,128 + FF FF FF

  代码中调用的 HMI_AddWave 函数实现（hmi.c）：
    void HMI_AddWave(const char *wave, uint8_t ch, uint8_t val)
    {
        char buf[32];
        snprintf(buf, sizeof(buf), "add %s,%d,%d", wave, ch, val);
        HMI_SendRaw(buf);
    }

  ★ 波形控件工作原理：
    - 每次收到 "add wave0,0,数值" 指令，就在波形末尾追加一个点
    - 当点数超过控件宽度时，自动向左滚动（旧点移出，新点加入）
    - 数值范围 0~255，对应 Y 轴从底到顶
    - ADC 12bit(0~4095) 右移 4 位 → 0~255 刚好映射

  清空波形指令（hmi.c）：
    void HMI_ClearWave(const char *wave, uint8_t ch)
    {
        char buf[24];
        snprintf(buf, sizeof(buf), "cle %s,%d", wave, ch);
        HMI_SendRaw(buf);
    }
    // 等价于发送：cle wave0,0 + FF FF FF

【控件7】开始按钮 (b_start)

    txt     = "开始"
    x       = 120
    y       = 365
    w       = 120
    h       = 45
    bco     = 0x00AA00     ← 按钮背景色（绿色）
    pco     = 0xFFFFFF     ← 文字颜色（白色）
    font    = 20
    radius  = 8            ← 圆角半径
    printh  = 53 54 41 52 54 0D 0A   ← ★ 关键！十六进制 ASCII "START\r\n"

  ★★★ printh 配置说明 ★★★
  在右侧属性面板中找到 printh 属性（一般在「事件」分类附近，或搜索 printh）
  填入：53 54 41 52 54 0D 0A
  含义：
    53 = 'S', 54 = 'T', 41 = 'A', 52 = 'R', 54 = 'T'
    0D = '\r' (回车), 0A = '\n' (换行)
  效果：每次按下按钮，屏通过串口发送 "START\r\n"

  对应代码（main.c 中 HMI_RxHandler 函数）：
    if (strcmp((char *)rx_buf, "START") == 0)
    {
        capture_on = 1;
        HMI_SetText("t_info", "采集运行中");
    }

四、按钮事件与代码完整对应关系
================================================================

┌──────────┬───────────────────────────┬──────────┬───────────────┐
│ 按钮     │ printh 属性值             │ 点击后   │ 屏发回内容    │
├──────────┼───────────────────────────┼──────────┼───────────────┤
│ b_start  │ 53 54 41 52 54 0D 0A     │ 开始采集 │ "START\r\n"   │
│ b_pause  │ 50 41 55 53 45 0D 0A     │ 暂停采集 │ "PAUSE\r\n"   │
│ b_clear  │ 43 4C 45 41 52 0D 0A     │ 清除波形 │ "CLEAR\r\n"   │
└──────────┴───────────────────────────┴──────────┴───────────────┘

printh 是淘晶驰按钮控件的内置属性，含义是"按下按钮时通过串口发送十六进制数据"。
末尾 0D 0A 是 \r\n（回车换行），帮助 STM32 端识别一条指令结束。

★ 为什么用 printh 而不是"发送键值"/"打印"？
  - "发送键值"发的是裸数字，屏编译器不认识 → 报"无效指令:2"
  - "打印"在部分版本里会把字符串当变量名检查 → 报"变量名称无效:START"
  - printh 是纯十六进制发送，屏编译器不检查内容 → 不报错，直接透传

接收端代码流程：
  触摸按钮 → printh 发十六进制 → 屏TX串口输出 ASCII 字节 →
  STM32 RX中断 → HMI_RxHandler 逐字节存入 rx_buf →
  遇到 \n 结束 → strcmp 匹配 "START"/"PAUSE"/"CLEAR" → 执行操作

验证方法（XCOM，字符模式）：
  点击屏上「开始」按钮 → XCOM 接收区应显示：START
  点击「暂停」 → XCOM 接收区应显示：PAUSE
  点击「清除」 → XCOM 接收区应显示：CLEAR

五、编译与下载流程
================================================================

1. 确认所有控件 objname 命名正确：
   ✓ t_freq    — 频率显示文本
   ✓ t_vpp     — 峰峰值显示文本
   ✓ wave0     — 波形控件
   ✓ t_info    — 状态提示文本
   ✓ b_start   — 开始按钮（printh = 53 54 41 52 54 0D 0A）
   ✓ b_pause   — 暂停按钮（printh = 50 41 55 53 45 0D 0A）
   ✓ b_clear   — 清除波形按钮（printh = 43 4C 45 41 52 0D 0A）

2. 点击工具栏「编译」按钮（或按 F7）
   → 等待编译完成，提示"编译成功"
   → 在工程目录下生成 .tft 文件

3. 下载到屏（两种方式）：

   【方式A】SD卡下载（推荐，稳定）
   a. 准备一张 MicroSD 卡（≤32GB，格式化为 FAT32）
   b. 将 .tft 文件复制到 SD 卡根目录
   c. 确保屏已断电
   d. 将 SD 卡插入屏的卡槽
   e. 屏上电 → 自动检测 SD 卡 → 开始烧录（屏上显示进度）
   f. 等待提示"下载完成" → 屏断电 → 取出 SD 卡 → 重新上电

   【方式B】串口下载
   a. 上位机 → 工具 → 串口下载
   b. 选择 COM 口和波特率（115200）
   c. 点击「下载」→ 根据提示给屏上电

4. 验证：上电后应看到默认界面
   - 顶部显示"频率：-- Hz  峰峰值：-- V"
   - 中部黑色波形区域（带网格）
   - 底部三个按钮 + 状态栏

六、XCOM 串口调试验证
================================================================

在连接 STM32 之前，先用 XCOM 直接与屏通信，确认硬件和协议正确。

接线：
  USB转TTL模块  TX  →  屏 RX
  USB转TTL模块  RX  →  屏 TX
  GND ←→ GND
  屏 VCC 接 5V 外接电源

XCOM 设置：
  串口：选择对应的 COM 口
  波特率：115200
  数据位：8
  停止位：1
  校验位：None
  ☑ 以十六进制发送（勾选）

测试指令（每条指令末尾都要加 3 字节 FF FF FF）：

  测试1 — 设置频率文本：
    文本输入：t_freq.txt="1000.0 Hz"
    勾选"发送新行" → 发送
    再切换到十六进制发送 → 发送：FF FF FF
    预期：屏上频率区域显示 "1000.0 Hz"

  测试2 — 设置峰峰值文本：
    文本输入：t_vpp.txt="3.300 V"
    发送（文本模式）
    再发送 FF FF FF（十六进制）
    预期：屏上 Vpp 区域显示 "3.300 V"

  测试3 — 追加波形点：
    文本输入：add wave0,0,128
    发送（文本模式）
    再发送 FF FF FF（十六进制）
    预期：波形区域出现一个点

  测试4 — 连续追加多个点（验证波形滚动）：
    用串口调试助手的"定时发送"功能，每 50ms 发送：
      add wave0,0,<随机值>
    观察波形是否持续滚动

  测试5 — 清空波形：
    文本输入：cle wave0,0
    发送 + FF FF FF
    预期：波形区域清空

  测试6 — 触摸按钮回传验证：
    用手指点击屏上的「开始」按钮
    XCOM 接收区应显示：START
    点击「暂停」→ PAUSE
    点击「清除」→ CLEAR
    （可能带换行符，正常）

  ★ 如果点击按钮后 XCOM 没有任何输出，检查：
    - USB转TTL的 RX 是否接屏 TX
    - 按钮事件是否配置为「弹起事件→打印→输入字符串」
    - 波特率是否匹配（115200）

七、常见问题
================================================================

Q1：按钮点击后 STM32 没有反应？
A1：
  - 检查 USART1 RX 中断是否开启（CubeMX NVIC 勾选）
  - 检查 main 中是否调用 HAL_UART_Receive_IT 启动接收
  - 用 XCOM 先验证：点击按钮，XCOM 能收到 START/PAUSE/CLEAR 字符串
  - 如果 XCOM 能收到但 STM32 无反应 → 检查 PA10 是否接屏 TX
  - 如果 XCOM 也收不到 → 检查按钮 printh 属性是否填对

Q2：点击按钮后屏报"无效指令"或"变量名称无效"？
A2：
  - 你用了"发送键值"或"打印"功能，而非 printh
  - 解决方法：删掉事件面板中所有旧配置
  - 在按钮属性面板中找到 printh，填入对应十六进制值
  - 不要碰「事件」面板里的任何选项

Q3：频率显示一直是 "DC / No Signal"？
A2：
  - 信号幅度必须跨越 1.65V 中点（ADC 值 2048 上下）
  - 检查信号发生器偏移设置
  - 用万用表测 PA0 电压，确认在 0~3.3V 内有波形

Q4：波形显示混乱 / 不像原始波形？
A3：
  - 信号频率过高 → 115200 下高频会混叠，正常现象
  - 信号超出 0~3.3V → 被削波
  - 尝试降低信号频率到 100Hz 以下验证

Q5：文本刷新时屏闪烁？
A4：
  - 当前代码每 300ms 更新一次文本，闪烁不明显
  - 若仍闪烁，可降低更新频率（改 300 为 500）

Q6：波形控件 Y 轴方向反了？
A5：
  - 淘晶驰 waveform 的 0 在底部、255 在顶部
  - 当前代码 adc_val>>4 直接映射，若觉得反向可改为：
    v = 255 - (uint8_t)(adc_val >> 4);
